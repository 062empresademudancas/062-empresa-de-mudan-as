PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new repository (for example, 062-mudancas-goiania).
2. Upload index.html to the repository's root folder (not inside another folder).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then save.
6. Wait for GitHub Pages to publish. Open the Pages URL shown in Settings → Pages.
